# Noon Egypt

مهمة واحدة بالترتيب. بيانات الدخول تُقرأ من `.env` ولا تُرفع مع الكود.

```powershell
npm ci
npx playwright install chromium
copy .env.example .env
npm start
```

1. يفتح المتصفح على تسجيل الدخول ويكتب البريد وكلمة المرور، ثم يحفظ الجلسة حتى لو لم يكتمل الدخول.
2. يغلق المتصفح ويفتحه من جديد بنفس الجلسة.
3. يضيف منتجًا إلى المفضلة، ثم يفتح المفضلة ويحذفه.
4. يفتح أي منتج، يذهب إلى الدفع، ويملأ بيانات البطاقة بدون الضغط على الدفع أو التأكيد.
5. يغادر الدفع، يغيّر الاسم في البروفايل، ويحفظه.
6. يفتح التوصيل ويغيّر العنوان. إذا طُلب تحقق يخرج منه ويكمل.
7. يبحث عن `سماعات`، يتمرر لآخر الصفحة، ويفتح صفحة فيسبوك الخاصة بنون.
